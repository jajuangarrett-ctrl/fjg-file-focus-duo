This is the separate local **0.1.0 preview**, not a phone-verified release. No original plugin or repository was modified; the product is not installed.

“Retained source” means the original implementation/settings are present and reachable in the listed place; it does not mean every live integration was executed. ## Evidence and limits

- `tests/browser/results.json` records the four dimensions and 17 acceptance groups, with zero browser page errors. Actual file visibility: outer drawer 7; inner drawer 8; outer tab 10; inner tab 10.
- Every original settings default is retained, including Include files from subfolders=true, Fixed Buttons and Header=true, and Reveal Active File Button=false. The leading-space command suffix ` create-new-note` is preserved.
- Preview is a retained capability implemented as a Markdown modal on touch, rather than reliance on a hover-only popup. Split-open on mobile uses a new tab with a notice. System trash on mobile uses Obsidian .trash with a notice. Missing companions and clipboard/open errors display notices.
- UI geometry is a Chromium fixture result at the measured Obsidian panel sizes, not proof of identical iOS theme/font/keyboard/footer behavior. The four physical baseline captures are research inputs, not product acceptance tests.
- Original Inventory names Quick Format’s dependency as note-format; code inspection shows AI Grammar Corrector. The integration was preserved as implemented.
- A feature’s placement is mapped even where validation is pending. No unsupported runtime capability is claimed to work on the physical Duo yet.
